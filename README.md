# PythonProject4

Учебный проект по теме «Введение в ООП».

## Описание проекта

В проекте реализованы классы Product и Category.

Класс Product предназначен для хранения информации о товаре. Для каждого товара указываются:
* название
* описание
* цена
* количество

Класс Category предназначен для хранения информации о категории товаров. Для каждой категории указываются:
* название
* описание
* список товаров

Также в классе Category реализован автоматический подсчёт:
* количества созданных категорий
* общего количества товаров во всех категориях

## Наследование и ограничения операций

В проект добавлены классы Smartphone и LawnGrass, наследующие класс Product.

### Класс Smartphone

Хранит дополнительные характеристики смартфона:

- efficiency — производительность;

- model — модель;

- memory — объём памяти;

- color — цвет.

### Класс LawnGrass

Хранит дополнительные характеристики газонной травы:

- country — страна-производитель;

- germination_period — срок прорастания;

- color — цвет.

### Ограничения операций

- Сложение разрешено только для объектов одного класса.

- При попытке сложить объекты разных классов возникает исключение TypeError.

- В категорию можно добавлять только объекты класса Product и его наследников.

### Тестирование

Для проверки новой функциональности добавлены автоматические тесты.

## Абстрактные классы и миксины

- Создан абстрактный класс BaseProduct, содержащий общую функциональность продуктов.

- Класс Product наследуется от BaseProduct.

- Добавлен класс-миксин PrintMixin, который выводит информацию о классе и параметрах объекта при его создании.

- Миксин включён в цепочку наследования класса Product.

- Для новой функциональности написаны автоматические тесты.
